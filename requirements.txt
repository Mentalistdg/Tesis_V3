# NOTAS DE INSTALACION:
# =============================================================================
#
# 1. TA-Lib (IMPORTANTE - Requiere instalacion especial):
#
#    WINDOWS:
#      a) Descargar wheel precompilado desde:
#         https://github.com/cgohlke/talib-build/releases
#      b) Elegir el archivo correcto para Python 3.13:
#         TA_Lib-0.6.8-cp313-cp313-win_amd64.whl
#      c) Instalar con: pip install TA_Lib-0.6.8-cp313-cp313-win_amd64.whl
#
#    LINUX/MAC:
#      a) Instalar la libreria C primero:
#         - Ubuntu/Debian: sudo apt-get install ta-lib
#         - Mac: brew install ta-lib
#      b) Luego: pip install TA-Lib
#
# 2. PyTorch: Si tiene GPU NVIDIA, instalar la version CUDA:
#    pip install torch --index-url https://download.pytorch.org/whl/cu118
#
# 3. Darts incluye automaticamente:
#    - prophet (Facebook Prophet)
#    - pytorch-lightning
#    - tensorboard
#    - neuralforecast
#
# 4. LaTeX (para compilar el paper):
#    - Windows: Instalar MiKTeX desde https://miktex.org/download
#      o TeX Live desde https://tug.org/texlive/windows.html
#    - Linux: sudo apt install texlive-full
#    - Mac: brew install --cask mactex
#
# 5. Node.js (para el frontend):
#    - Descargar Node.js v22.x desde https://nodejs.org/
#    - Luego: cd app/frontend && npm install
#
# 6. Tiempo de instalacion estimado: 10-15 minutos
# 7. Espacio en disco requerido: ~5 GB (PyTorch + dependencias)
#
