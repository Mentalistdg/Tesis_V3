# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

S&P 500 return prediction system combining Elder's Triple Screen methodology with 92 Bloomberg financial variables transformed into 536 features. Trains 23 ML/DL models, optimizes per-model quantile thresholds via Meta-KNN (non-oracle), and runs a Long-Only backtest ({0, +1, +3} positions via CASH/SPY/UPRO). Includes a full-stack visualization app and a LaTeX academic paper.

**Author:** David Gonzalez Canon
**Test Period:** October 2020 - December 2025 (1,302 days)
**Dataset:** 6,507 observations (Jan 2000 - Dec 2025), 536 features

## Architecture

### ML Pipeline Flow

```
BLOOMBERG_RAW_DATA.csv (92 vars, immutable input — must exist in data/ before running pipeline)
  →1 [build_dataset.py] → bloomberg_triple_screen_core.csv (536 features)
  →2 [train_models.py] → trained_artifacts.pkl + models/checkpoints/ (23 models, ~198 MB)
  →3 [optimize_and_backtest.py] → final_long_only_backtest.json + long_only_equity_curves.json
                                   + optimal_model_params.json + backtest_detail.pkl
  →4 [paper/update_backend_data.py] → app/backend/data/*.json (bridges pipeline → web app)
  →  [paper/generate_paper_figures.py] → paper figures (run before compiling)
  →  [paper/generate_paper_tables.py] → LaTeX tables (run before compiling)
```

**train_models.py** uses a checkpoint system: each model saves individually to `models/checkpoints/` (sklearn as `.joblib`, Darts as directories, PyTorch as `.pt`), then `trained_artifacts.pkl` stores only metadata + predictions (lightweight). Memory is freed via `gc.collect()` after each model.

Checkpoint layout: `models/checkpoints/{sklearn/*.joblib, darts/*/*, pytorch/*.pt, preprocessors.joblib}`

**optimize_and_backtest.py** (step 3) combines threshold optimization and backtesting into a single script using two components:
1. **Meta-KNN Threshold Prediction**: Trains KNN(K=5, distance-weighted) on training-data meta-features to predict optimal `(q_ext, q_mod)` thresholds dynamically for each test day. No future data used.
2. **Signal Quality Filter**: Filters out degenerate models with near-constant predictions (rolling 63-day std < 0.001) by defaulting to CASH. Prevents percentile ranking from amplifying noise.

## Critical Constraints

### Data Leakage Prevention
- All features use only past data (`pct_change`, `rolling`, `shift(>=1)`). The **only** `shift(-1)` in the entire system is the target `forward_returns`.
- Train/test split is **temporal** (80/20, split at Oct 2020). Never shuffle.
- Preprocessing (scaler, imputer) fitted only on training data.
- Rolling percentiles for position sizing look backward only.
- **Threshold optimization** uses Meta-KNN trained exclusively on training data. No test-period information is used to determine `(q_ext, q_mod)`.
- **No warmup removal**: `build_dataset.py` does NOT remove the first 252 rows. NaN from rolling windows in early rows are imputed by `SimpleImputer(median)` during model preprocessing in `train_models.py`. The `warmup_period` config was removed (was dead code).

### Strategy Logic (Long-Only)
Predictions → rolling 63-day percentile → discrete positions:
- Percentile >= `100 - q_long_extreme` → +3 (UPRO, 3x leveraged)
- Percentile >= `100 - q_long_moderate` → +1 (SPY)
- Otherwise → 0 (CASH)

Thresholds `(q_ext, q_mod)` are predicted dynamically each test day by KNN based on 7 meta-features of recent prediction behavior. If rolling prediction std < 0.001, the signal is classified as degenerate and the position defaults to CASH.

**Return formula:** `r = rf + position * (market_return - rf)`

**Costs:** UPRO expense 0.91%/yr, SPY 0.09%/yr, bid-ask spreads (UPRO 5bps, SPY 2bps on position changes), volatility drag for 3x ETFs (`0.5 * 6 * sigma^2` daily, where `sigma` is realized rolling 21-day vol — backward-only, NOT a fixed constant since the June 2026 cost fix).

### Reproducibility
Global seed `42` set for NumPy, PyTorch, and all sklearn models. `requirements.txt` uses `==` (pinned versions) for reproducibility.

## Models (23 trained)

| Category | Models (code keys in results JSON) |
|----------|--------|
| Classical ML | Ridge, Lasso, ElasticNet, RandomForest |
| Gradient Boosting | GradientBoosting, XGBoost, LightGBM, CatBoost |
| Time Series (Darts) | AutoARIMA, ExponentialSmoothing, Theta, SeasonalNaive |
| Specialized | Prophet, GARCH |
| Deep Learning (Darts) | DLinear, NBEATS, NHiTS, TCN, TFT |
| Custom PyTorch | CNN_LSTM, LSTM_Attention, BiLSTM, BiGRU |

**Paper taxonomy (4 families, 4/4/6/9 = 23):** the paper and `generate_paper_tables.py` (`MODEL_CATEGORIES`) group these 6 code-categories into 4 families — **ML clásico** (Ridge/Lasso/ElasticNet/RandomForest), **Boosting** (GradientBoosting + XGBoost/LightGBM/CatBoost), **Series temporales** (Time Series + Specialized), **Deep learning** (Deep Learning Darts + Custom PyTorch). Note `GradientBoosting` (sklearn vanilla) lives in the **Boosting** family (decided June 2026), not Classical ML. The family is named "Boosting" (not "Gradient boosting") to avoid redundancy with the `GradientBoosting` model name (and "GBM" was avoided as it reads as Geometric Brownian Motion in finance).

## Latest Results (June 2026 — Meta-KNN + Signal Filter, post cost-model fix)

4/23 models beat SPY Buy & Hold (+101.3%, Sharpe 0.657) using non-oracle Meta-KNN thresholds with signal quality filter. Top performers: LSTM_Attention (+395.4%, Sharpe 1.319), Ridge (+252.5%, Sharpe 0.856), RandomForest (+127.5%, Sharpe 0.651, maxDD −15.0%), CNN_LSTM (+122.2%, Sharpe 0.572, maxDD −35.9%). See `results/final_long_only_backtest.json` for current numbers. Re-running the pipeline produces identical results with the pinned dependencies.

**These June 2026 numbers supersede the earlier April 2026 figures** (SPY +102.2%, LSTM +400%, Ridge +263%) that appeared before the volatility-drag/benchmark cost fix. The fix replaced a fixed σ=1% in the 3x leverage decay with realized rolling 21-day vol (backward-only), netted SPY B&H by its 0.09% expense ratio, and charged the realized vol drag to the UPRO benchmark (now +122.8%, Sharpe 0.26). Still 4/23 beat SPY. If you see LSTM +400% / SPY +102.2% anywhere, that source is stale.

Previous oracle-based results (March 2026) showed 7/23 models beating SPY, but those thresholds were optimized over the test period. The current 4 genuine winners use thresholds determined exclusively from training data.

## Paper Writing Style

The paper follows a specific writing fingerprint derived from the author's prior work. **Future agents MUST follow these rules when editing .tex files:**

- **NO colons (`:`) in prose text.** Replace with commas, semicolons, "a saber", "dado que", "es decir", "ya que", "puesto que", or restructure the sentence. LaTeX commands like `\section{}` are fine.
- **NO em-dashes (`---`) in prose text.** Professors identify em-dashes as AI-generated text. Replace with commas, semicolons, parentheses, "dado que", "a saber", "es decir", "ya que", "puesto que", or restructure. Table-cell placeholders (`---` for N/A) and LaTeX comments are fine.
- **NO bullet points** in prose sections, everything in flowing paragraphs.
- **NO footnotes (`\footnote{}`).** Definitions go in the glossary appendix (`appendix_glossary.tex`) with `\hypertarget{glos:key}{term}` and the term in text uses `\hyperlink{glos:key}{display text}`. Clarifications are integrated inline ("dado que", "es decir", parenthetical clauses, etc.). URL sources become `\bibitem` entries in the bibliography.
- Formal impersonal voice ("se propone", "se documenta"), NOT first-person plural ("proponemos"). Exception: the personal reflection paragraph in the conclusion uses first person.
- Technical English terms in `\textit{}` (e.g., `\textit{deep learning}`, `\textit{drawdown}`).
- Long flowing sentences with subordinate clauses connected by commas and connective phrases.
- Spanish body text typed WITHOUT accents (US keyboard), accents only via LaTeX escapes (`\'o`, `\'a`, `\'e`, `\'i`, `\'u`, `\~n`).
- **Avoid repeated connectors** in the same sentence or adjacent sentences. Vary between "dado que", "ya que", "puesto que", semicolons, etc.
- APA-style citations: `\citet{}` for textual, `\citep{}` for parenthetical. Bibliography is manual `\begin{thebibliography}`, not `.bib` files.
- **Avoid repetition across sections.** If a fact (e.g., "536 features", "4 models beat SPY") was already stated, refer to it generically ("los hallazgos documentados", "los modelos ganadores") instead of restating specific numbers.
- **Humble tone** (professor's requirement): use "sugiere", "parece indicar", "podría ser" instead of "demuestra", "confirma", "establece", "contradice". The paper is a thesis with results for two ETFs in one period — not definitive proof.
- **ALWAYS compile after editing .tex files** — the user expects to see the compiled PDF.
